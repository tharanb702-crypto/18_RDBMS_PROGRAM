# 18-RDBMS-PROGRAM
# PL/SQL Function – Count Students by Department

## Question

Write a PL/SQL function to count the number of students available in a particular department.

## Objective

To create a PL/SQL function that accepts a DepartmentID and returns the number of students belonging to that department.

## Student Table

The Student table contains:

- StudentID
- StudentName
- DOB
- Gender
- DepartmentID

## Expected Result

The function should return the total number of students belonging to the specified department.

## Example

If DepartmentID 101 has 2 students, the function should return:

2
